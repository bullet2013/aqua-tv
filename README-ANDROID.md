# AQUA TV — Android APK (пробная версия)

Это **не готовый APK**, а проект Android + JavaScript-интеграция и GitHub Actions для сборки APK.

## Что работает по замыслу

- Интерфейс, M3U, компактный EPG, логотипы и изменения дизайна загружаются с `https://bullet2013.github.io/aqua-tv/`.
- HTTP HLS-видеопотоки воспроизводятся **нативным Media3/ExoPlayer**, а не WebView. Это убирает ошибку Mixed Content именно для видеопотоков.
- Телевизионный пульт / стрелки / Enter обрабатываются существующим JavaScript. Android Back превращается в Esc.
- Экран просмотра остаётся единым: нативное видео находится за прозрачным WebView, HTML-инфобар и телепрограмма поверх видео.
- Сохраняется выбранный канал и индивидуальный размер шрифта в localStorage приложения.

## Подготовка файлов на GitHub (bullet2013/aqua-tv)

1. Распакуйте ZIP. В корне репозитория замените **`index.html`**, **`app.js`** и **`styles.css`** файлами из архива. `index.html` обновляет версии файлов в ссылках, чтобы WebView не использовал старый кэш. JS и CSS содержат дополнительный Android-режим, но обычная браузерная версия продолжит работать через hls.js.
2. Добавьте папку **`android/`** целиком, сохранив вложенность `app/src/main/...`.
3. Добавьте **`.github/workflows/android-apk.yml`**. Старый `.github/workflows/pages.yml` НЕ удаляйте.
4. Сделайте commit в ветку `main`.
5. Вкладка **Actions** → **AQUA TV — Android APK** → **Run workflow** → **Run workflow**. После успешной сборки появится **Artifacts → AQUA-TV-Android-APK**.
6. Скачайте артефакт (ZIP), распакуйте `app-debug.apk`, перенесите на устройство и установите. В Android потребуется разрешить установку из выбранного источника.

> GitHub Actions собирает **debug APK** с тестовой подписью. Он предназначен для личной проверки, не для Google Play. Для релизного APK понадобится собственный сертификат подписи.

## Android Studio

Откройте папку `android/` в Android Studio, дождитесь Gradle Sync, затем **Build → Build APK(s)**. Установочный debug APK будет в `android/app/build/outputs/apk/debug/`.

## Требования и ограничения

- Устройство: Android 6.0+ (API 23), актуальный Android System WebView, доступ к GitHub Pages и сети IPTV-провайдера.
- APK сам по себе **не снимает ограничение провайдера по IP/сети**: поток должен быть доступен устройству.
- В коде Android намеренно разрешён единственный хост IPTV — `31.41.12.104` (`ALLOWED_STREAM_HOSTS` в `MainActivity.java`). Если в плейлисте есть потоки с других IP/хостов, добавьте их в набор разрешённых хостов и пересоберите APK.
- Не ставьте WebView в режим Mixed Content Always Allow: HTTP воспроизводится через ExoPlayer, а веб-сайт остаётся HTTPS.
- Если устройство не поддерживает конкретный видеокодек, ExoPlayer не гарантирует его воспроизведение.
- **Пробная версия, не проверенная на реальном Android-устройстве.** При первом запуске могут потребоваться доработки отображения нативного видео за прозрачным WebView на конкретном телевизоре/прошивке.
- В используемой среде **нет Android SDK или доступа к сборке**. Поэтому готовый APK здесь не создан; используйте GitHub Actions, где необходимые компоненты скачиваются автоматически.

## Где меняется адрес сайта

`android/app/src/main/java/io/github/bullet2013/aquatv/MainActivity.java`, константа `SITE`.

## Безопасность

- JavaScript → Android сообщения идут через `WebViewCompat.addWebMessageListener` только от `https://bullet2013.github.io`, основного фрейма.
- На устройстве проверяется хост видеопотока по белому списку.
- Запрещена навигация WebView на посторонние сайты. Режим `Mixed Content` отключён.

# AQUA TV — GitHub Pages + компактный EPG (на основе интерфейса 1.14.1)

Готовый статический сайт с общим EPG для Firefox/TV. Node.js используется **только** в GitHub Actions при подготовке EPG (или в `server.mjs` на localhost); посетителям и браузеру Node.js не нужен. Не устанавливаются npm-зависимости.

## Быстрая установка

1. Создайте **публичный** репозиторий `aqua-tv` на GitHub (для GitHub Free).
2. Распакуйте архив, затем загрузите **содержимое** папки проекта, а не сам ZIP, в корень ветки `main`. Проверьте, что в репозитории есть `index.html`, `app.js`, `styles.css`, `config.js`, `playlist.m3u`, `.github/workflows/pages.yml`, `tools/epg-update.mjs` и `tools/sync-playlist.mjs`.
3. Укажите плейлист одним из двух способов:
   - **Самый простой:** замените демонстрационный `playlist.m3u` полным своим M3U и отправьте файл в репозиторий.
   - **Автосинхронизация с существующим публичным репозиторием:** откройте Settings → Secrets and variables → Actions → Variables → New repository variable. Создайте `AQUA_PLAYLIST_URL` со значением прямого HTTPS URL файла, полученного кнопкой **Raw** в GitHub. Например: `https://raw.githubusercontent.com/USER/MY-PLAYLIST/main/playlist.m3u`. При каждом запуске Actions этот файл скачивается и используется как `playlist.m3u` на опубликованном сайте. Если переменная задана, она имеет приоритет над демонстрационным/загруженным M3U. Для приватных репозиториев эта схема без токена не подходит.
4. В Settings → Pages → Build and deployment → **Source: GitHub Actions**.
5. Во вкладке Actions откройте «AQUA TV — сайт и компактный EPG» → **Run workflow**. После зелёной отметки откройте Pages-ссылку из настроек (пример `https://USER.github.io/aqua-tv/`).
6. В логах Actions проверьте строку `[EPG] Успешно: N каналов, M передач, ... МБ gzip`. Число совпавших каналов должно быть > 0. Если сборка упала, откройте последний лог Actions — ошибка EPG будет показана там.

GitHub Actions автоматически **раз в сутки** скачивает оригинальный EPG по адресу `https://iptvx.one/EPG` (FULL с описаниями), читает уникальные `tvg-id` из M3U, оставляет записи за сутки назад и на 4 дня вперёд, формирует **один** компактный `epg.xml.gz` и `epg-meta.json`. Каждый браузер забирает этот файл с GitHub Pages и хранит EPG в собственном IndexedDB. В памяти телевизора разбирается только компактный файл; исходный 70 МБ GZIP не передаётся посетителям.

**Лайт-версия без описаний:** если понадобится, измените `epgUrl` в `config.js` на `https://iptvx.one/EPG_LITE`, либо задайте в Variables `AQUA_EPG_URL` с другим HTTPS-адресом источника XMLTV.

### Где лежит плейлист после автосинхронизации?

Сам workflow публикует скачанную копию `playlist.m3u` рядом с HTML в GitHub Pages. В репозиторий отдельным коммитом эта копия не записывается: она живёт **в опубликованной сборке**. При запуске workflow источник перечитывается. Логотипы из исходного `tvg-logo` остаются как есть и скачиваются напрямую по HTTPS.

### Где хранятся телепередачи и как обновляются?

- GitHub Actions ежедневно **вычисляет новый** `epg.xml.gz`, не загружая исходный XML целиком в RAM.
- На GitHub Pages готовый файл доступен как `https://USER.github.io/aqua-tv/epg.xml.gz`.
- Браузеры проверяют метаданные раз в 15 минут, обновляют собственный кэш и используют EPG для прогрессбаров и описаний.
- Если GitHub Actions не смог скачать XMLTV или не нашёл подходящие передачи, сборка завершится ошибкой; предыдущий опубликованный EPG останется на сайте.
- По умолчанию период программы — ближайшие 4 дня. В `config.js` параметр `epgDaysAhead` оставлен 3: сам плеер показывает более короткое окно, готовый EPG содержит запас.

### Важно: HTTP-трансляции на HTTPS-сайте

GitHub Pages обслуживается по HTTPS. Ваши HLS-адреса типа `http://31.41.12.104:2222/...` **могут не воспроизводиться и обычно блокируются** браузером как mixed content. Это не ошибка AQUA TV или GitHub Actions. Для просмотра потребуется законный HTTPS HLS-источник с нужными CORS-заголовками, либо отдельный доверенный HTTPS-прокси. Сам GitHub Pages поток не проксирует. На localhost по HTTP текущие ссылки могут работать, если источник допускает такие подключения и кодеки поддерживаются.

Не публикуйте в публичном репозитории секретные токены, персональные доступы и приватные подписные плейлисты. Проверьте право распространять эти потоки и EPG.

### Локальный запуск

Windows: `start-localhost.bat` (Node.js 20+), либо через любой локальный статический сервер. Для общей автоматической загрузки EPG на localhost запускайте `node server.mjs`; обычный статический сервер сам общий XMLTV-файл обновлять не может. Если репозиторий ещё не настроен или прямой EPG недоступен из вашей сети, браузер может сообщить, что локальный EPG отсутствует — это ожидаемо.

### Обновление интерфейса

Когда мы изменяем AQUA TV, достаточно заменить `index.html`, `app.js`, `styles.css` в репозитории. GitHub Actions автоматически пересоберёт сайт и EPG. Файлы `config.js` и `playlist.m3u` не заменять без необходимости.

### Ограничения GitHub

GitHub Pages — публичный статический хостинг, а не видео-хостинг. Запуски Actions по расписанию иногда задерживаются. Если в публичном репозитории нет активности 60 дней, GitHub может автоматически отключить запланированные workflow; периодически проверяйте вкладку Actions.
